# ShoPperZ

## Responsive E-Commerce Website

ShoPperZ is a responsive front-end e-commerce website built using HTML, CSS, and Vanilla JavaScript.

The project focuses on clean UI, responsive navigation, and interactive product search functionality.

---

# Features

## Responsive Navigation
- Desktop and mobile-friendly header
- Hamburger menu for mobile devices
- Auto-close mobile menu on link click

## Working Menu Links
- HOME → Hero section
- SHOP → Home section
- OUR PRODUCTS → Products listing
- CONTACT US → Footer section
- ABOUT US → Brand/About section

# How It Works

## Search Logic
- JavaScript listens to keyboard input
- Filters products by name
- Scrolls to products section using scrollIntoView()
- Handles empty state with a “No product found” message

## Menu Logic
- Mobile menu toggled using class manipulation
- Links scroll smoothly to page sections
- Menu closes automatically after navigation
