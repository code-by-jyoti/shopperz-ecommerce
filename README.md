# ShoPperZ

## Responsive E-Commerce Website

ShoPperZ is a responsive front-end e-commerce website built using HTML, CSS, and Vanilla JavaScript.

The project focuses on clean UI, responsive navigation, and interactive product search functionality.

---

# Features

## Responsive Navigation
- Desktop and mobile-friendly header
- Hamburger menu for mobile devices
- Auto-close mobile menu on link click

## Working Menu Links
- HOME → Hero section
- SHOP → Home section
- OUR PRODUCTS → Products listing
- CONTACT US → Footer section
- ABOUT US → Brand/About section

## Live Product Search
- Real-time product filtering while typing
- Automatically scrolls to products section
- Displays matching products
- Shows “No product found” message
- Restores products when input is cleared

## UI & Design
- Clean and modern layout
- Hover effects and transitions
- CSS variables for theming
- Responsive product grid
- Mobile optimized layout
