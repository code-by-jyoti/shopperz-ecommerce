# ShoPperZ

ShoPperZ is a responsive front-end e-commerce website built using HTML, CSS, and Vanilla JavaScript.

## Current Features

### Responsive Header
- Logo section
- Desktop navigation
- Search bar structure
- Mobile hamburger menu UI

### Hero Image Slider
- Multiple banner images
- CSS sliding animation
- Responsive scaling

### Product Grid
- Responsive product cards
- Product image, name, price, description
- Hover zoom effect

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Ionicons

- Product grid layout
